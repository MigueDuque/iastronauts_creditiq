# NIIF 13 — Medición del Valor Razonable

## Propósito
Define el valor razonable, establece un marco único para medirlo y exige revelaciones sobre las mediciones. El valor razonable es el precio que se recibiría por vender un activo o se pagaría por transferir un pasivo en una transacción ordenada entre participantes del mercado.

## Requisitos de revelación
- Jerarquía del valor razonable (Nivel 1, 2 y 3) según la observabilidad de los datos de entrada.
- Técnicas de valoración e insumos utilizados para Nivel 2 y Nivel 3.
- Conciliación de saldos de apertura y cierre para las mediciones de Nivel 3.
- Transferencias entre niveles y las razones que las motivan.
- Análisis de sensibilidad de las mediciones de Nivel 3 a cambios en datos no observables.

## Checklist — qué revelar
- [ ] Clasificación de cada medición por nivel de jerarquía.
- [ ] Técnica de valoración e insumos clave.
- [ ] Movimiento de Nivel 3 (saldo inicial → final).
- [ ] Transferencias entre niveles.
- [ ] Sensibilidad de las mediciones de Nivel 3.
